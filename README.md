# AWS CloudFormation - Infraestrutura como Código (IaC)

## Sobre o projeto

Este projeto foi desenvolvido como parte do desafio prático da plataforma DIO, com o objetivo de aplicar os conceitos de Infrastructure as Code (IaC) utilizando o AWS CloudFormation.

A proposta consiste em compreender como automatizar a criação e o gerenciamento de recursos na AWS por meio de templates declarativos.

## Objetivos de aprendizagem

- Compreender o funcionamento do AWS CloudFormation.
- Conhecer os conceitos de Infrastructure as Code (IaC).
- Criar infraestrutura utilizando templates YAML.
- Automatizar o provisionamento de recursos na AWS.
- Documentar processos técnicos utilizando GitHub.

## Tecnologias e serviços utilizados

- Amazon Web Services (AWS)
- AWS CloudFormation
- Amazon EC2
- YAML
- Git e GitHub

## Conceitos estudados

### Infrastructure as Code (IaC)

Infrastructure as Code é uma abordagem que permite gerenciar e provisionar infraestrutura por meio de arquivos de configuração, tornando o processo mais automatizado, padronizado e reproduzível.

### AWS CloudFormation

Serviço da AWS utilizado para modelar, provisionar e gerenciar recursos de infraestrutura por meio de templates.

### Templates

Arquivos YAML ou JSON que descrevem os recursos que serão criados na infraestrutura.

### Stacks

Conjunto de recursos provisionados e gerenciados pelo CloudFormation a partir de um template.

## Implementação prática

Durante o laboratório, foram explorados os conceitos de criação e gerenciamento de infraestrutura automatizada utilizando AWS CloudFormation.

As etapas práticas incluem:

1. Criação de um template CloudFormation.
2. Definição dos recursos necessários.
3. Provisionamento da infraestrutura.
4. Acompanhamento da criação da Stack.
5. Verificação dos recursos criados.
6. Documentação dos resultados obtidos.

## Aprendizados

Com este laboratório, pude compreender a importância da automação de infraestrutura na computação em nuvem.

O uso do CloudFormation permite reduzir tarefas manuais, padronizar ambientes e facilitar a reprodução de infraestruturas.

Também foi possível compreender como a abordagem Infrastructure as Code contribui para a organização, escalabilidade e manutenção de ambientes AWS.
